## PROCESS

### 1 / Prepare privately
Separate what happened from what you think it means.

Name what you are protecting, what you have actually observed, and what would change your mind.

### 2 / Work the problem together
Clarify the real work outcome.

Make both the opportunity and the cost visible.

Use prior evidence if it already answers the question.

### 3 / Design one credible test
Only if a useful uncertainty remains.

Set task, tool, approval, quality bar, protected time, comparator, stop rule, and decision owner **before** beginning.

### 4 / Decide
Count the full cost.

Then **Continue / Revise / Stop / Pause**.

Leave with an owner and a reason.
