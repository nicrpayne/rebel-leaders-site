# AI Stalemate V1 Prototype

Standalone prototype work for **Rebel Leaders Field Tool 01 — AI Stalemate**.

This folder is deliberately **outside the Rebel OS / Workbench runtime**. It exists to validate a simple paid product before we add accounts, team state, Praxis, plugins, or deeper platform integration.

## V1 path

landing → $47 checkout → two field guides + browser lab → useful decision → feedback

## Files

- `PRODUCT_CONTRACT.md` — binding V1 scope.
- `LANDING_COPY.md` — copy deck.
- `landing.html` — responsive interactive landing-page mockup.
- `lab.html` — functional local-first Stalemate Lab prototype.
- `LAUNCH_CONTENT.md` — six video/post concepts.
- `HANDOFFS.md` — prompts for parallel PDF, landing, Lab, and QA workstreams.

## Run locally

Open `landing.html` and `lab.html` directly in a browser.

The Lab uses localStorage only. No account, backend, sync, or Rebel OS integration is required for V1.

## Checkout

`landing.html` contains a `CHECKOUT_URL` constant. Replace the empty string with the final hosted checkout URL.

## Hard rule

Do not turn V1 into a platform.

Ship the smallest thing that proves whether Product and Engineering leaders will pay to move from an AI argument to a decision they can defend.
